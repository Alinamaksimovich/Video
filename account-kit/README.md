# Аварийный набор: перенос на новый аккаунт Claude

Здесь всё, чтобы новый аккаунт Claude работал так же, как этот: правила, навыки, плейбуки, бренд-ассеты, инструменты.
Папка лежит в GitHub-репозитории `Alinamaksimovich/Video` (ветка `claude/repository-connection-0pkkvc`).
**Сделай ещё и копию на свой компьютер**: скачай репозиторий как ZIP (GitHub → Code → Download ZIP) или возьми `account-kit.zip`, который я прислал в чат.

## Что где лежит
| Что | Где | Зачем |
|---|---|---|
| Профиль и правила работы | `CLAUDE.md` (и в корне репозитория) | Claude Code читает его сам; новый аккаунт сразу знает, как ты работаешь |
| Текст для вставки в чат | `prompt-for-new-account.md` | Одно сообщение, после которого новый Claude подхватывает контекст |
| Список навыков | `skills-index.md` | Что установлено, откуда, для чего |
| Сами навыки (Claude Code) | `../.claude/skills/` | 64 навыка, подхватываются автоматически при открытии репозитория |
| Твои навыки из claude.ai | `account-skills/` + `*.zip` | `design-taste` (библиотека вкуса) и `instagram-posts-premium` |
| Плейбуки по типам работ | `playbooks/` | Как собираются рилсы, титры, звук, онбординг, кейсы |
| Бренд-ассеты | `brand/` | Логотипы PROMPTICA, шрифты (HeliosExt, Fluctuation, Roboto Flex), палитры |
| Эталонные скрипты | `tools-ref/` | Генераторы музыки (house, phonk, dnb, garage), SFX-раскладка, титры, монтаж |
| SFX-библиотека | `../sfx-library/` | Твои звуки + описание, для чего какой |
| Готовые проекты | `../videos/`, `../onboarding-trends/` | Исходники всех видео и онбординга |
| Установка зависимостей | `setup.sh` | Python-пакеты, модели речи, проверка ffmpeg и HyperFrames |

## Как восстановиться за 5 шагов
1. Открой новый аккаунт на claude.ai/code и подключи GitHub (https://claude.ai/connect-github), дай доступ к репозиторию `Alinamaksimovich/Video`.
2. Запусти сессию на этом репозитории, ветка `claude/repository-connection-0pkkvc` (или `main`, если ветку уже влили).
3. Вставь в чат текст из `prompt-for-new-account.md`.
4. Попроси: «Запусти `bash account-kit/setup.sh`» (поставит зависимости и модели).
5. В claude.ai (веб) загрузи два ZIP (`design-taste.zip`, `instagram-posts-premium.zip`, лежат рядом с этим README) в Settings → Capabilities → Skills и вставь текст предпочтений из `playbooks/claude-ai-account-checklist.md`.

## Что перенести файлами нельзя (сделать руками)
- Подключения (Figma, GitHub, Google), их нужно заново авторизовать.
- Память и настройки профиля: текст предпочтений есть в `playbooks/claude-ai-account-checklist.md`.
- Загруженные тобой исходники (озвучки, видео, фото клиентов), если их нет в репозитории: храни оригиналы на диске. Сейчас в репозитории лежат только обработанные копии.
