# Профиль и правила работы (читать первым)

## Кто пользователь
Директор AI-агентства PROMPTICA (prompticadigital.com): дизайн, видео, реклама, SMM, контент. Задачи: делать контент
и продвигать агентство. Клиенты и проекты: MIRRO (онлайн-гардероб), WeArt Studio (weartstudio.io), кейсы Hey (газированный
сок) и Avelor (матча). Пишет по-русски, пишет в женском роде.

## Как отвечать
- По-русски, коротко, без «воды». Сначала результат, потом пара строк, что сделано и что осталось решить.
- Для нового видео сначала описать сценарий таблицей по секундам, согласовать, потом собирать. Спрашивать только то, без чего нельзя
  продолжать (материалы, слоган, музыка); остальное решать самому и сказать, что выбрано.
- Не придумывать то, чего пользователь не просил. Если фраза двусмысленна, выбрать разумную трактовку и назвать её.
- Отвечать на вопрос, когда просят «пока не делай, просто ответь».
- Результат (mp4) отправлять файлом в чат, плюс коротко: что внутри, громкость, что не проверено (звук не прослушан агентом).

## Видео: главные правила
1. **Голос не трогать.** Только усиление (gain) и нормализация. Никакой компрессии, EQ, шумодава («как будто в банке»).
2. **Баланс.** Голос ≈ 80%, музыка + SFX ≈ 20%. Музыка на ~15 дБ ниже речи, SFX не перебивают слова. Итог ≈ −14 LUFS, пики ≤ −1 dBFS.
3. **Музыка своя, оригинальная** (генерируется кодом, `tools-ref/`). Не повторять один трек в разных видео; каждый раз новый жанр
   (уже были: electro-pop, deep house, phonk, drum & bass, 128 BPM electro, UK garage). Если просят «без музыки», её нет.
4. **SFX из библиотеки пользователя** (`sfx-library/`), под ритм и появления элементов. Не заезженные «трендовые» звуки.
5. **Не брать материалы с сайта** в видео PROMPTICA. Если сказано «подставляй только загруженные видео», использовать только их.
6. **WeArt:** в рекламе не называть конкретные модели ИИ, без цены и триала в креативах. В онбординге и на экранах приложения модели называть
   (актуальные: Nano Banana 2, GPT Image 2, Kling 3.0, Seedance 2.5, Veo 3.1, ElevenLabs v3).
7. **Кейс Hey:** не писать, что делали дизайн упаковки: был пустой макет банки и PDF с дизайном, делали визуал и рекламные видео.
   **Кейс Avelor:** дизайн упаковки + визуал + видео.
8. **Шрифт:** если пользователь прислал шрифт, им и писать все титры (HeliosExt, Fluctuation). По умолчанию Roboto Flex (кириллица есть).
9. **Мало моушна, когда просят** («не надо много моушн-дизайна»): жёсткие склейки на словах, лёгкое появление строк, без лишних эффектов.
10. **Титры:** см. `playbooks/captions.md`: 2 строки по 2 слова, без переноса слов, строго по центру зоны, фиксированные позиции, без случайных сдвигов.
11. **Видео-пауза и «дёргания»:** вырезать длинные паузы, моргание, лишние вдохи в начале; склейки без видимых скачков.
12. **Формат:** 9:16 (1080×1920) для рилс, 16:9 (1920×1080) для презентаций; делать обе версии, если просят «такое же вертикальное».

## Проверка перед отправкой (обязательно)
- `npm run check` без ошибок; рендер `npx hyperframes@0.8.138 render --workers 1 -o renders/<имя>.mp4`.
- Посмотреть кадры (`ffmpeg ... tile`), особенно: переполнение текста, центровка, перекрытия, пустые кадры в начале.
- Громкость: `ffmpeg -af ebur128=peak=true`, затем одно усиление/loudnorm на готовом видео, видеопоток копировать (`-c:v copy`).
- Для титров измерять центровку по кадрам, а не на глаз.
