# Как писать описание визуала (для дизайнера и для нейросети)

Скилл выдаёт не только текст, но и **описание визуала** — чтобы дизайнер или нейросеть (Midjourney, DALL·E, Nano Banana, Sora-image и т.п.) сделали макет в нужной эстетике.

## Что описывать по каждому слайду
1. **Сюжет:** что в кадре (объект/модель/фактура/рендер).
2. **Палитра:** база + один акцент. Если пользователь дал фирменные цвета — используй их; иначе описывай словами (графит, кремовый, глубокий красный).
3. **Композиция:** где герой, сколько воздуха, симметрия/ассиметрия.
4. **Типографика:** где крупный заголовок, где мелкий моноширинный, где ®/нумерация.
5. **Настроение:** editorial, лабораторное, люксовое, минималистичное.

## Шаблон промпта для нейросети (EN, работает лучше)
> Editorial fashion still, [subject], on [background/texture], muted [palette] with a single [accent color] accent, lots of negative space, premium minimalist composition, soft studio light, high detail texture, magazine art direction, no text — text will be added in design.

Важно: проси нейросеть генерить **фон/арт без текста**, а текст-заголовок ставить на макете в дизайне (Figma/Canva) — так типографика останется чистой и управляемой.

## Библиотека визуальных сюжетов (из референсов)
Бери как вдохновение под тему:
- Крупный портрет с необычной фактурой кожи/грима (веснушки, металлик, вода).
- Fashion-модель в динамике: чёрное платье, ткань в движении, editorial-поза.
- Природная фактура крупно: груша, лист, дюны, цветок, камень, мёд, зелень.
- 3D-рендер продукта на чистом фоне с каплями/текстурой.
- Объект в неожиданном контексте (камень на листе, хамелеон на очках).
- Тёплый интерьер-натюрморт (мебель, лампа, кремовые тона) для ART-кейсов.

## Фирменный акцент promptica (по умолчанию)
- **Фирменный красный promptica (#B1202D, RGB 177,32,45)** — акцент по умолчанию для всех постов агентства. Он и есть «один акцент на пост». Совпадает по духу с красным smm.lava — премиум-совместим. Файлы лого — в `assets/`.
- База под него: белый / кремовый / графит / чёрный.
- Фирменная деталь: круг-капля (точка над `i` в лого) — можно выносить как графический маркер, буллет или акцентную точку в макете.
- Для клиентских постов допускаются другие акценты (см. ниже), но для постов самого promptica держи фирменный красный.

## Акцентные цвета и их смысл
- **Глубокий красный** — премиум, страсть, «продаёт» (сигнатура ЛАВА и promptica).
- **Кислотный жёлтый / лайм** — энергия, спорт, современность (ovyonlabs KOMMA/Lue).
- **Янтарь / мёд** — люкс, тепло, косметика/парфюм (071).
- **Ч/б + один холодный акцент** — строгий имидж, технологичность (OPAC).
Один акцент на пост. Через ленту — держи ограниченный набор акцентов, чтобы профиль читался как система.

## Чек-лист «выглядит ли дорого»
- [ ] Есть воздух, макет не забит текстом.
- [ ] Один акцентный цвет, не радуга.
- [ ] Заголовок крупный, остальное мелкое.
- [ ] Есть мелкая техническая деталь (нумерация/®/код).
- [ ] Фото — editorial/арт, не сток.
- [ ] Палитра совпадает с остальной лентой.
