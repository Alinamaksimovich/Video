# Форматы: карусель / одиночный пост / reels-обложка

## 1. Карусель (основной формат для пользы и кейсов)

Оптимум 5–8 слайдов. Структура:

- **Слайд 1 — ХУК.** Крупный заголовок капсом + подзаголовок мелким. Задача — остановить пролистывание. Самый сильный визуал.
- **Слайд 2 — контекст/проблема.** 1–2 предложения, зачем читать дальше.
- **Слайды 3–N-1 — тело.** Одна мысль на слайд, у каждого мини-заголовок. Для кейса (ART): этапы работы, роли, детали проекта. Для пользы (EXPERT): пункты, шаги, инструменты.
- **Последний слайд — вывод + CTA.** Резюме одной строкой + мягкий призыв (сохранить / написать / забрать). Логотип агентства.

Визуальная связность: единая палитра и один акцент через всю карусель, сквозная нумерация слайдов мелким моноширинным (01/07, 02/07…).

## 2. Одиночный пост (имидж, анонс, манифест)

Один макет должен работать сам по себе.
- Крупный заголовок/название проекта капсом.
- Сильное editorial-фото или 3D-рендер как арт.
- Мелкие технические подписи по краям (роли, ®, спеки, код проекта).
- Вся глубина — в подписи под постом.
Лучше всего для ART-режима и анонсов.

## 3. Reels-обложка + текст

Обложка reels должна держать стиль ленты, даже если видео динамичное.
- Заголовок капсом поверх кадра — читаемый на превью в сетке.
- Тот же премиум-код: воздух, один акцент, мелкая техподпись.
- В подписи — раскрытие + CTA.
- Учитывай, что в сетке профиля обложка стоит рядом с другими — держи единый визуальный ритм ленты.

## Единство ленты (важно для премиума)
Все четыре референса сильны именно системностью ленты, а не отдельными постами:
- Повторяющаяся палитра и один тип акцента.
- Единый шрифт заголовков через все посты.
- Ритм: чередование «фото-арт» и «текст на фоне», но в одной эстетике.
- Фирменный знак/логотип в одном месте.
Когда генеришь серию постов — держи их как систему, а не как разрозненные макеты.
