# Звук: правила и инструменты

## Правила
- **Голос** пользователя: без обработки. Скрипты только ресемплируют и применяют одно усиление (`soundtrack.py` в `promptica-course`, `weart-canvas`).
- **Баланс:** голос ≈ 80%, музыка + SFX ≈ 20%; музыка под речью на ~15 дБ ниже; на паузах между фразами можно приподнять.
- **Громкость:** −14 LUFS, пики ≤ −1 dBFS (`alimiter`).
- **Музыка:** оригинальная, процедурная, каждый раз новый жанр. Не использовать одну и ту же дорожку в разных видео.
- **SFX:** только из `sfx-library/` (описание в `sfx-library/README.md`). Появления карточек: pops/ui-pack; вспышка/затвор: camera; печать: `ui-pack/typing`;
  жидкость: `impacts`; переходы: `transitions`. Ставить по таймингам анимации, уровень −8…−22 дБ (под голосом ещё тише).
- Если просят «музыку не надо»: только голос + тихие SFX.

## Генераторы музыки (`tools-ref/`)
| Файл | Жанр / темп | Где использован |
|---|---|---|
| `weart-canvas__house.py` | deep house, 109 BPM | WeArt canvas reel |
| `promptica-course__phonk.py` | фонк, 167 BPM | PROMPTICA course reel |
| `promptica-presentation__dnb.py` | drum & bass, 174 BPM | PROMPTICA презентация 16:9 |
| `promptica-cases__garage.py` | UK garage, 132 BPM | PROMPTICA кейсы |
| `weart-promo/tools/soundtrack.py` | electro 100/128 BPM | WeArt promo, UGC |
Каждый скрипт детерминирован (фиксированный seed), пишет WAV 44.1 кГц, строит сетку по тактам (`at(bar, beat)`), чтобы анимация шла строго в долю.
Новый жанр: взять ближайший скрипт, поменять BPM, лад, аккорды, паттерны барабанов и тембры.

## Раскладка SFX
`promptica-cases__sfx.py`, `promptica-nodes-9x16__audio.py`: список `CUES = [(файл, время, дБ)]`, нормализация каждого звука по пику, сумма, общий лимит.

## Озвучка и речь
- TTS (если нужна): Kokoro (kokoro-onnx), голоса `am_michael`, `af_heart`; сейчас пользователь чаще записывает голос сам.
- Распознавание: sherpa-onnx Whisper small (ru). Разбить дорожку по паузам, распознать сегменты, словами подогнать титры.
