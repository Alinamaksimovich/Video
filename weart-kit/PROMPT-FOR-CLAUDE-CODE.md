# Промпт для нового Claude Code (скопируй целиком в первый чат)

```
Ты работаешь в папке с готовым набором материалов для WeArt Studio. Прежде чем делать что-либо, прочитай и пойми структуру. Выполни по шагам.

ШАГ 1. Определи корень.
Найди папку, в которой лежат файлы README.md, CLAUDE.md, WEART.md и каталоги videos/, onboarding/, sfx-library/, .claude/skills/. Это корень набора. Все пути ниже считай от него. Если рядом лежит папка account-kit/, это общий набор правил автора (агентство, другие бренды): прочитай и её account-kit/CLAUDE.md, при конфликте правил WeArt-правила главнее для задач по WeArt.

ШАГ 2. Прочитай в таком порядке (целиком, не по диагонали).
1. README.md: что где лежит.
2. CLAUDE.md: правила работы. Следуй им во всех задачах.
3. WEART.md: бренд, палитра, шрифты, фразы, цены, список моделей и ограничения.
4. onboarding/README.md: онбординг, 8 экранов.
5. videos/<проект>/index.html и videos/<проект>/tools/*.py для каждого из 5 проектов (weart-promo, weart-ugc, weart-canvas, weart-guy, weart-cta). Нужно понять, как собраны ролики и звук.
6. sfx-library/README.md: какой звук для чего.

ШАГ 3. Проверь, что все материалы на месте.
- Папка videos/*/assets/video и файл videos/weart-guy/assets/source.mp4 лежат в отдельном архиве (weart-kit-sources.zip). Если их нет, не пытайся их придумать: скажи, каких файлов не хватает.
- Готовые ролики лежат в final-renders/ (отдельный архив). Если папки нет, это нормально.

ШАГ 4. Навыки.
В .claude/skills/ лежат навыки (video, анимация, GSAP, дизайн). Любую видеоработу начинай с навыка hyperframes и дальше используй профильные (hyperframes-core, hyperframes-audio, media-use, motion-graphics, gsap-* и т.д.) по их описаниям. Не создавай видео без них.

ШАГ 5. Установка.
Запусти bash setup.sh и покажи отчёт (что установилось, что нет). Если нужны модели речи и озвучка, запусти bash setup.sh --models. Ничего не удаляй и не переписывай в папке, пока я не попрошу.

ШАГ 6. Жёсткие правила (повтор главного, чтобы не потерять).
- В рекламе WeArt не называть конкретные модели ИИ и не писать цену или триал. В онбординге и на экранах приложения модели называть.
- Голос автора не обрабатывать: только громкость. Баланс: голос ≈ 80%, музыка и SFX ≈ 20%. Итоговая громкость ≈ −14 LUFS, пик ≤ −1 dBFS.
- Музыка оригинальная, каждый раз новый жанр, без повторов дорожек; звуки только из sfx-library.
- Титры: 2 строки по 2 слова, без переноса слов, строго по центру зоны, без случайных сдвигов.
- Сначала описать сценарий таблицей по секундам и согласовать со мной, потом собирать.
- Перед отправкой результата: npm run check, посмотреть кадры рендера, измерить громкость, потом отдать файл.
- Фото с оружием (onboarding/photos/trend-04-rifle-carpet.jpg) в интерфейсе не использовать.
- Отвечай по-русски, коротко, без воды.

ШАГ 7. Отчёт.
Ответь одним сообщением (не длиннее 15 строк): 
1) что нашёл (список проектов и что в каждом), 
2) чего не хватает, 
3) какие навыки доступны, 
4) результат setup.sh, 
5) что ты понял про правила WeArt своими словами. 
Потом жди моей задачи и ничего не запускай без неё.
```
