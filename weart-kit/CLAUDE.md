# Правила работы: WeArt Studio (читать первым)

## Как отвечать
- Коротко, без «воды». Сначала результат, потом пара строк: что сделано и что решить.
- Для нового видео сначала сценарий таблицей по секундам, согласовать, потом собирать.
- Перед отправкой: `npm run check`, посмотреть 8–12 кадров рендера, замерить громкость, затем отправить mp4 файлом.

## Бренд и ограничения: см. `WEART.md`
Главное: в рекламе не называть модели ИИ, без цены и триала; в онбординге модели называть; фото с оружием в UI не использовать.

## Видео (HyperFrames)
- Композиция: `index.html` с GSAP-таймлайном `paused`, зарегистрированным в `window.__timelines["main"]`, `immediateRender:false`.
- Рендер: `cd videos/<проект> && npx --yes hyperframes@0.8.138 render --workers 1 -o renders/<имя>.mp4`; проверка: `npm run check`.
- Звук: голос только усиливать; музыку генерировать скриптами `tools/*.py` (каждый раз новый жанр: были electro, deep house); SFX из `sfx-library/`.
- Громкость −14 LUFS, пик ≤ −1 dBFS: `ffmpeg -af ebur128=peak=true`, затем одно усиление, видеопоток копировать.
- Титры: 2 строки по 2 слова, строго по центру зоны, без случайных сдвигов.
- Монтаж живого видео: вырезать паузы и дёргания, склейки без скачков (пример `videos/weart-guy/tools/edit.py`, список `CHUNKS`).

## Онбординг
8 экранов в Claude Design (`*.dc.html` + `canvas.json`), 390×844. Холст может править человек вручную: перед публикацией перечитывать изменённые файлы и накатывать правки поверх. Подробности: `onboarding/README.md`.

## Навыки
Лежат в `.claude/skills/` (видео, анимация, GSAP, дизайн). Начинать видеоработу с навыка `hyperframes`.

## Окружение
Нужны: Node 22, Python 3.10+ (numpy, scipy, soundfile, kokoro-onnx), ffmpeg, Chromium. Установка и проверка: `bash setup.sh` (с флагом `--models` докачивает модели речи).
