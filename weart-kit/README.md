# WeArt Studio: набор для видео и онбординга

Всё, что сделано для WeArt Studio (weartstudio.io): рекламные ролики, UGC, рилсы, призыв-вставка, онбординг приложения, правила, навыки для Claude Code и звуки.
Чтобы получить то же самое на своём компьютере или в своём Claude, достаточно распаковать архив и открыть папку в Claude Code.

## Что внутри
| Папка / файл | Что это |
|---|---|
| `CLAUDE.md` | Правила работы и все договорённости по WeArt. Claude Code читает его сам |
| `prompt-for-new-person.md` | Одно сообщение для первого чата, после него Claude подхватывает контекст |
| `WEART.md` | Бренд: цвета, шрифты, тексты, фразы, правила рекламы, список моделей, цены |
| `onboarding/` | Онбординг приложения, 8 экранов: исходник холста, 9 фото трендов, README |
| `videos/` | 5 видеопроектов (исходники, скрипты звука, раскладки) |
| `final-renders/` | Готовые ролики (mp4) |
| `.claude/skills/` | Навыки Claude Code для видео и анимации (HyperFrames, GSAP, motion и др.) |
| `sfx-library/` | Библиотека звуковых эффектов с описанием, что для чего |
| `setup.sh` | Установка нужных программ и проверка |

## Видеопроекты (`videos/`)
| Проект | Что это | Формат |
|---|---|---|
| `weart-promo` | Рекламный ролик WeArt Studio: «все нейросети в одном месте», доска, монтаж трендов. Версия v3, 25 сек, без названий моделей, английская озвучка (Kokoro), электро-музыка | 9:16 |
| `weart-ugc` | UGC-вариант: озвучка + кадры, электро 128 BPM | 9:16 |
| `weart-canvas` | Рилс: видео автора улетает вверх на фразе «I was made in a few clicks», canvas-моушн, deep house 109 BPM, голос без обработки | 9:16 |
| `weart-guy` | Монтаж 30-секундного видео «парня»: убраны дёрганье глаз и паузы, добавлены SFX | 9:16 |
| `weart-cta` | Призыв 2,7 сек: кнопка «Подписаться» / «Try now», вариант с голосом и без | 9:16 |

Каждый проект: `index.html` (композиция HyperFrames), `tools/*.py` (музыка, звук, озвучка, монтаж), `assets/` (картинки, звук, шрифты).
Большие исходные видео (`assets/video/*`, `source.mp4`) в этот архив не входят, они лежат в архиве `weart-kit-sources.zip`: распакуй его поверх этой папки, и структура совпадёт.

## Как начать (5 шагов)
1. Распакуй архивы в одну папку `weart-kit/`.
2. Установи Claude Code и открой в нём эту папку (или загрузи её в claude.ai/code как репозиторий).
3. Вставь в чат текст из `prompt-for-new-person.md`.
4. Попроси: «Запусти `bash setup.sh`» (проверит ffmpeg, Node, Python-пакеты, HyperFrames).
5. Работай задачами: «сделай рилс…», «собери креатив…», «поменяй экран онбординга…».

## Собрать любое видео заново
```
cd videos/weart-promo
python3 tools/soundtrack.py          # музыка и звук (тексты озвучки в tools/voiceover.py, нужны модели Kokoro, см. setup.sh --models)
npm run check
npx --yes hyperframes@0.8.138 render --workers 1 -o renders/weart-promo.mp4
```
Для `weart-canvas`, `weart-guy` нужны исходные видео из `weart-kit-sources.zip`.
