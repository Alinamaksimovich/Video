# SFX library

Shared sound effects for all videos in this repo. Copy what a project needs into
its own `assets/sfx/` (HyperFrames serves files from the project folder).

## camera/ — DSLR / film camera (48 kHz stereo)
| File | Length | Use for |
|---|---|---|
| SJC_DSLR_Menu_Tick_02.wav | 0.05 s | tiny UI tick: counters, list steps, cursor moves |
| SJC_DSLR_Focus_Beep_01.wav | 0.20 s | "locked in": a card lands, a value hits its target |
| SJC_DSLR_Focus_Beep_02.wav | 0.17 s | second focus beep, for doubles / variations |
| SJC_DSLR_Flash_Close_02.wav | 0.25 s | flash pop closing: end of a reveal, logo settles |
| SJC_FILMCAMERA_Leaf_Shutter_04.wav | 0.21 s | shutter click: photo/frame cuts, white flashes, product shots |
| SJC_FLASHBULB_Flashbulb_05.wav | 2.87 s | old flashbulb pop + whine tail: big reveal, hero logo, end card |
